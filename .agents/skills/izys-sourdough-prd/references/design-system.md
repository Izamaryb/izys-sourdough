# Design System

## Colors

* Primary Text: #4A3B2F
* Background: #FDFBF8
* Secondary: #706351
* Accent: #A2978A
* Border: #D4CEB2

### Accessibility Fix

* Button: #5D5344
* Hover: #4A3B2F
* Text: #FDFBF8

## Typography

* Headings: Lora (700)
* Body: Montserrat (400–500)

### Mobile Sizes

* H1: 32px
* H2: 26px
* H3: 20px
* Body: 18px
* Small: 16px
* Button: 16px

## Spacing

4, 8, 16, 32, 48, 64 px scale

## Border Radius

* 8px everywhere

## Components

### Buttons

* Primary: dark olive background, cream text
* Secondary: outline

### Cards

* Padding: 24px
* Light border
* Rounded corners

### Inputs

* Border: accent
* Focus: darker accent

## Product Card States

Default:

* Image, name, price, button

Hover:

* Slight scale (1.02)
* Subtle shadow

Sold Out:

* Blurred image
* "SOLD OUT" overlay
* Disabled button
